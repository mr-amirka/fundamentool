# css — значения CSS из короткой записи

[English version](./README.md)

`fundamentool/css` (fundamentool D-095) переводит короткую запись в значения CSS: математику с единицами, переменные,
цвета, градиенты. Ещё он строит условие медиа и дочерний комбинатор.

## Когда нужен

- Превратить короткую запись в CSS-значения: математику с единицами — в `calc()`, переменную — в `var(--x, fallback)`,
  цвет с прозрачностью, градиенты.
- Медиа-запрос для брейкпоинта — в классическом (`max-width`) или range-синтаксисе.
- CSS-in-JS или инструмент утилитарных классов, который пишет CSS из своей записи (minotation).

Ядро знает CSS и то, как читать. **Запись — вызывающего**: символы группы и переменной, имена функций, части
градиента. Всё это обязательно; записи по умолчанию нет (lab D-044). minotation читает свою нотацию одной записью
(`{…}`, `Min{…}`). Объект стилей в TypeScript может взять другую (`(…)`, `min(…)`).

```ts
import { cssValuesProvider, mathRules, cssMediaCondition, childCombinator } from 'fundamentool/css';

// один раз: запись (проверяется в разработке)
const css = cssValuesProvider({
  group: ['(', ')'], variable: '$', env: '$$', nameEnd: ';',
  functions: { min: 'min', max: 'max', clamp: 'clamp' },
  gradient: { join: '-', stop: 'p', angle: '_g', radial: '_r', repeat: '_rpt', space: '_' },
});
// один раз на свойство: единица голого числа, допустимые единицы, минус
const bottom = mathRules({ name: 'bottom', unit: 'px', units: ['px', 'rem', '%'] });

css.math('16+$$safe-area-inset-bottom(0)', bottom); // 'calc(16px + env(safe-area-inset-bottom, 0px))'
css.math('100%-2*$gap', bottom);                    // 'calc(100% - 2 * var(--gap))'
css.math('1/3', bottom);                            // '33.33%'
css.math('min(100%,50rem)', bottom);                // 'min(100%, 50rem)'
css.bare();                                         // 0 — в последнем значении не было оператора вне группы
css.variable('$mono(serif)');                       // 'var(--mono, serif)'; не переменная — undefined
css.color('$ink(F00)');                             // ['var(--ink, #f00)']
css.color('F00.5', true);                           // ['#f00', 'rgba(255,0,0,.5)'] — запасной первым
css.gradient('F00-00F_g90');                        // ['linear-gradient(270deg,#f00 0%,#00f 100%)']

cssMediaCondition('width', '<', '480px', 'classic'); // '(max-width: 479.98px)'
cssMediaCondition('width', '<', '480px', 'range');   // '(width < 480px)'
childCombinator(2);                                  // '>*>'
```

Ридеры не используют `this`, поэтому `const { math, color } = css;` работает.

## Математика

- **Голое число** получает единицу свойства там, где оно терм (`10` → `10px`). Там, где оно множитель, оно остаётся
  числом: `$gap*2` → `calc(var(--gap) * 2)`, а `10*2` → `calc(10px * 2)`.
- **Число над числом** — дробь в процентах (`1/3` → `33.33%`), но только первым множителем произведения. Дальше `/`
  делит.
- **Один терм** пишется без `calc`; с операторами `calc` появляется.
- **Значение, которое целиком группа,** читается как её содержимое: `(1+2)` → `calc(1px + 2px)`.
- **Единица, которую свойство не берёт,** — ошибка, где названы допустимые единицы.
- **Минусу перед первым термом** нужен `negative: true`.
- **Ноль** пишется `0`. Внутри математики он с единицей, потому что `calc(0 + 5px)` CSS не принимает.
- **`bare()`** возвращает `1`, если в последнем значении, прочитанном `math`, был оператор вне всех групп (`1/2+32`,
  `$a*2`). minotation строит на этом подсказку «математика без скобок».

## Запись

| Опция | Что это | Пример |
|---|---|---|
| `group` | символы группы; ими же пишутся аргументы функции и запасной вариант переменной | `['(', ')']` |
| `variable` | перед именем переменной | `'$'`: `$gap` → `var(--gap)` |
| `env` | перед именем переменной окружения | `'$$'`: `$$x` → `env(x)` |
| `nameEnd` | заканчивает имя там, где оно могло бы продолжиться | `';'`: `$a;-2` → `var(--a)` минус 2 |
| `functions` | функции математики, как написаны → их имя в CSS (`min`, `max`, `clamp`) | `{ Min: 'min' }` |
| `gradient` | `join` между цветами, `stop`, `angle`, `radial`, `repeat`, `space` между словами радиальной формы | `F00p40-00F_g90` |
| `fail` | бросает ошибку вызывающего; по умолчанию `TypeError` с префиксом `[fundamentool/css]` | `(m) => { throw new MyError(m); }` |
| `legacy` | зовётся со значением там, где терм начинается с `--`: место для подсказки о прежней записи | «was renamed» у minotation |

Каждый символ записи — один символ. Он не может быть частью имени или математики (буквы, цифры, `-`, `_`,
`+*/,.%`). Два места не делят один символ; только `env` может начинаться с `variable`.

## Скорость

Ридеры — горячий путь. Математика держит состояние в переменных модуля, без замыканий и регулярных выражений на
вызов. Запись копируется в эти переменные, только когда перед этим работал ридер другого провайдера, и никогда — на
каждый символ. Изменения здесь проверяются бенчмарком компиляции minotation.
