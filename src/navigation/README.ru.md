# navigation

[English version](./README.md)

Стек страниц и окон, синхронный с историей браузера, кэш страниц и представление из внедрённой библиотеки отображения.
`import { createNavigation, createNavigationView, createBrowserHistory } from 'fundamentool/navigation'`.

- **Каждая страница и каждое окно — запись истории**: «назад» (браузер, Android, Escape) закрывает верхнее.
  `await nav.open(Window, params)` возвращает то, с чем окно закрылось (`null` — закрыто кнопкой «назад»).
- **Перекрытые страницы остаются смонтированными**, скрыты `display: none`; каждый слой — свой контейнер прокрутки,
  поэтому страница возвращается со своей прокруткой и данными (проверено в Chromium, WebKit, Firefox). Какие страницы —
  флаг маршрута `keep` и лимит количества (опция `keep`).
- **`replace(path)`** — заменить верхнюю страницу на месте, без новой записи истории («следующий уровень»).
- **Вкладки**: `sectionHistory: 'separate'` — у каждого раздела своя история; повторное нажатие на текущую вкладку
  откатывает её к главной странице; «назад» с главной страницы вкладки ведёт на первую вкладку.
- **Хуки**: `useWhileOpen` (открыта → начала закрываться), `useOnForward` (поверх страницы открывается что-то — `false`
  отменяет, промис задерживает шаг, возвращённая функция вызывается при возврате; окна — только с `{ windows: true }`),
  `useBeforeLeave` (спрашивается перед уходом назад — «отменить изменения?»), `useEntry`, `useNavigation`,
  `useNavigationState`.
- **Ничего не импортируется напрямую**: история — порт (`createBrowserHistory(window, 'hash' | 'path')`), библиотека
  отображения — набор (`React` или `preact` + `preact/hooks`).

Пример — в [README.md](./README.md). Тестовое приложение с пятью вкладками: web-games `frontend/labs/navigation`.
