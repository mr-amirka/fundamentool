# Роутер: страницы и окна

[English version](./README.md)

`routerProvider` / `hashRouterProvider` (`import { hashRouterProvider } from 'fundamentool'`) — модель URL и
наблюдаемые значения, которые у роутера были всегда (`$location`, `$path`, `$query`, `Link`, `NavLink`,
`paramStorage`, `routerByLocationProvider`, `onBeforeUnload`, …), на движке из этой папки (fundamentool D-022). Движок
внутренний: пользуйтесь роутером.

- **Каждая страница и каждое окно — запись истории**: «назад» (браузер, Android, Escape) закрывает верхнее.
  `await router.open(Window, params)` возвращает то, с чем окно закрылось (`null` — закрыто кнопкой «назад»). Окно
  сохраняет адрес страницы; стек окон в адресе не виден.
- **«Вперёд» работает**: то, с чего ушли кнопкой «назад», остаётся впереди, и кнопка браузера «вперёд» возвращает его —
  страницу с её адресом, окно — открытым заново с теми же параметрами (новое окно, его ответа никто не ждёт). Окна
  подтверждения отказываются: `router.open(ConfirmWindow, params, { reopen: false })` — «вперёд» перед ними
  останавливается (D-024).
- **Перекрытые страницы остаются смонтированными**, скрыты `display: none`; каждый слой — свой контейнер прокрутки,
  поэтому страница возвращается со своей прокруткой и данными (проверено в Chromium, WebKit, Firefox). Какие страницы —
  `describe` возвращает `keep: true`, не больше `keep` штук (опция, по умолчанию 10).
- **`replaceLocation`** заменяет верхнюю страницу на месте (окна над ней сначала закрываются); **`startOverLocation`**
  очищает историю (выход из аккаунта, сброс).
- **Вкладки**: `sections` + `sectionHistory: 'separate'` — у каждого раздела своя история; `switchSection(name)` на
  текущем разделе откатывает его к главной странице; «назад» с главной страницы раздела ведёт на первый раздел.
- **Наблюдатели**: `onBeforeUnload(cb)` — спрашивается перед уходом с текущей записи кнопкой «назад» (`false` её
  удерживает; может быть асинхронным); с `{ forwards: true }` — перед тем как поверх откроется страница или окно, в том
  числе кнопкой браузера «вперёд».
  `useRouteIsFocus(effect)` — работает, пока запись открыта, снимается, когда с неё начали уходить, и запускается снова,
  если уход отменён.
- **Представление**: `router.view(kit, { renderPage, renderWindow })` — хост и хуки `useWhileOpen`, `useOnForward`,
  `useBeforeLeave`, `useEntry`, `useNavigationState`, `useNavigation` (движок — переходы делайте методами роутера).
  Набор — `React` или `preact` + `preact/hooks`; окно браузера и библиотека отображения внедряются, а не импортируются.

Пример — в [README.md](./README.md). Тестовое приложение с пятью вкладками: web-games `frontend/labs/navigation`.
