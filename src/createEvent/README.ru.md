# `createEvent` — событие и производные от него события

[English version](./README.md)

Событие как в Effector (fundamentool D-049, D-105): то, что происходит, переданное от места, где случилось, тому, кто
на него действует. Класс, который сам источник событий — со своей событийной моделью, — наследует
[`EventEmitter`](../EventEmitter/README.ru.md) (D-111). Сторы — [`createObservable`](../createObservable/README.ru.md).

## Когда нужен

- Что-то происходит — клик, сохранение, сообщение, файл, который агент только что отредактировал, — и другие на это
  подписываются.
- Триггер, суженный (`filter`) или переформированный (`map`, `prepend`) по пути к тому, кто на него действует.
- Единица, из которой делаются другие события: суженные, переформированные, питающие стор (`createApi`).

```ts
const saved = createEvent<string>();                 // событие — то, что происходит
const stop = saved.watch((id) => toast(id));         // только при вызовах, никогда при подписке
saved('note-7');                                     // toast('note-7'); возвращает 'note-7'
const docs = saved.filter({ fn: (id) => id.startsWith('doc-') }).map((id) => id.slice(4)); // производные события
docs.watch((name) => open(name));
saved('doc-plan');                                   // toast('doc-plan'), затем open('plan')
const savedNote = saved.prepend((note: { id: string }) => note.id); // вызов вызывает saved с note.id
stop();
```

| Поведение | Как в Effector |
|-----------|----------------|
| `watch` срабатывает только при вызовах | `event.watch` |
| вызов события возвращает его payload | да |
| `watch` возвращает функцию, у которой есть и `{ unsubscribe }` | `Subscription` |
| `event.map(fn)`, `event.filter({ fn })` — производные события: наблюдаются, не вызываются (`TEventDerived`) | да |
| `event.prepend(fn)` — событие, вызывающее это с результатом `fn` | да |
| бросивший исключение наблюдатель логируется; остальные выполняются | да |

Производное событие ничего не держит, пока на него никто не подписан: на источник оно подписано от первого наблюдателя
до последнего (D-105). **Вызов ничего не копирует** (D-112): список наблюдателей заменяется при подписке и отписке, а
вызов читает список, с которым начался, — наблюдатель, добавленный во время вызова, услышит следующий.

Пока нет: `event.filterMap`, `sample`, скоупы — со своим Effector в fundamentool.
